# Autonomous-Submarine

### [YouTube Demonstration](https://youtube.com/shorts/z_gIspJPBr0?feature=share) 

<h2>Description</h2>
The goal of this project was to create a submarine that would submerge a few feet underwater (around 4-6 feet), and be able to move, steer, navigate to avoid obstacles, and control depth. I chose to use 4" PVC pipe for the hull because I had lots of it lying around, with 3D printed endcaps that held the motors and sensors. I designed a system to magnetically drive the propellers through the hull wall using neodymium magnets, ceramic bearings, and custom 3D printed parts. The sub detected its depth and surroundings using 3 sonar sensors mounted on the front in a custom nosecone.
